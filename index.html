02

How I test

Development taught me how features are put together. Diagnostics taught me how they fall apart. Both shape how I work.

  1. 01

    Understand

    Read the requirements and use the product as a customer would. Ask questions early: an unclear requirement is the cheapest bug to fix.

  2. 02

    Design

    Write checklists and test cases with equivalence partitioning, boundary values, decision tables and state transitions.

  3. 03

    Execute

    Run smoke, functional, regression, UI/UX and exploratory sessions on real devices. Watch the network in DevTools, call the API in Postman, verify data with SQL.

  4. 04

    Report

    File bug reports a developer can act on in minutes: clear steps, expected and actual result, environment, severity, evidence.
